To run, download the EXE, and then place the EXE file in your resource packs folder and run it, then follow on-screen instructions from there.

You can also choose to run the Python source instead, by downloading the PY file and putting it in your resource packs folder, then using CMD to CD into that directory and run it ("py mcmeta_upper.py"),
or simplier also just download the RUN.BAT and put that in the same folder with the PY file and then just run RUN.BAT and it will do that for you.
